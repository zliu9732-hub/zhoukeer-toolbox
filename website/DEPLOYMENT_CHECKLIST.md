# guide.jktool.icu 正式接入检查单

当前只完成帮助站内容准备，不执行购买、DNS 修改或公网部署。

正式接入前必须由维护者逐项确认：

- ICP 备案主体与备案状态可用于 `jktool.icu`。
- 已有可用于备案和中国大陆接入的云资源。
- 可以控制 `jktool.icu` DNS，并确认使用子域名 `guide.jktool.icu`。
- 首页、图文教程、视频教程、常见问题、错误码、诊断包说明、版本公告和下载校验说明已复核。
- Gitee Markdown 教程继续保留为临时入口和故障回退。
- 网站构建产物、图片和视频不进入工具箱更新包或 Git 历史中的发布包。
- 域名未备案或接入未完成时，不对外承诺中国大陆稳定直连。
