常见问题

先看Renkit给出的结果

下载失败：先点“检查网络”，Renkit会自动尝试已有线路，不需要手动选择镜像。

操作仍失败：生成诊断包发给维护人员；不要发送管理员密码文件、账号信息或完整 HOME。

系统更新后软件消失：SteamOS 更新可能移除系统级第三方软件，重新运行对应安装入口即可。

错误码

安全退出提示

NET-01：本地网络不可用，请检查 Wi-Fi。

NET-02：安全下载线路暂不可用，稍后重试或生成诊断包。

SAFE-01：空间、电量、系统保护或平台预检未通过，没有执行修改。

DL-01：下载来源、文件类型、大小或校验不符合要求，旧版本保持不变。

RESTORE-01：设置恢复失败，Renkit已尝试回到恢复前状态。

诊断包

只在本地生成，由你决定是否发送

诊断包包含Renkit版本、SteamOS 基础信息、网络检查、下载与更新状态和最近错误摘要。用户名、HOME、IP、MAC、密码、Token、Cookie、代理认证和远程协助凭据会被隐藏；管理员密码便利模式文件不会被读取或打包。

下载校验

为什么Renkit会拒绝“看起来能下载”的文件

Renkit只接受受控 HTTPS 来源，并检查超时、HTTP 错误、文件类型、大小、SHA256、版本和压缩包安全。网页、403 响应、异常压缩包、符号链接或校验不一致都会停止，不能为了安装成功降低安全标准。

发布包校验值以仓库中的 dist/SHA256SUMS 和 GitHub Release 附件为准。

正式国内站接入条件：在绑定 guide.jktool.icu 前，必须确认 ICP 备案、可备案的大陆云资源、DNS 控制权和子域名。本页面只是内容准备，不代表未备案域名能在中国大陆稳定直连，也没有购买云资源、修改 DNS 或部署公网网站。
