# ThemeHub 中文包更新

GitHub Actions 的 `sync-themehub-zh.yml` 每日触发，由 Unix 日期奇偶检查保证每 48 小时查询一次上游正式版本；跨月不改变间隔。手动运行和相关规则提交可以立即检查。沿用现有 `GITEE_TOKEN`，与其他中文包使用同一发布并发组。

## 保留现有汉化

- 已核对的 1.10.7 中文字典、渲染层、黄色 `RenAmamiya汉化` 署名保持原样。`themehub_ui_baseline.json` 记录真实原包的界面与后端文案清单，并关联原中文版的 SHA256。
- 比较新版真实安装包的界面标签、显示名称、异步状态、动态文案及后端返回文字。只翻译新增/变化的文字，已发布的增量译文继续复用，不允许覆盖现有措辞。
- 新增文字没有中文、动态片段遗漏、插件连接名称不一致、注入锚点变化或功能语法树变化时停止。新模板仅使用附加的显示转换；数据、路径、主题 ID、接口、Python 和运行资源不变。
- 先生成完整 ZIP、全量文件清单与界面检查报告。相同上游版本修复须提升 `REVISION`，不能只改字典后继续使用旧修订。

## 发布与安装

上游 API 不可用时，从官方正式版本和附件页面读取唯一 ZIP 及 SHA256。下载必须匹配该校验值。新中文包先上传到现有 Gitee 第四仓库，再从公开地址取回全部分块、组合完整 ZIP，并复验全部文件，最后才更新公开安装清单；失败时保持上一份清单。

Renkit 的主页主题安装入口读取已验证的最新清单；网络失败使用本地缓存和随 Renkit 打包的版本下限，禁止降级。安装前验证 ZIP 和所有文件，再复制到暂存目录复验，随后替换 `DeckHomeThemes`。安装目录复验成功后才删除旧目录；写入或校验失败时恢复旧版，避免重复插件。若旧文件清理失败，单独提示重试，不谎报回退成功。

插件内部名称与后端连接继续使用 `ThemeHub`。主题和设置位于 Decky 提供的运行目录和设置目录，更新不清理这两个目录。插件内部英文自更新入口仍引导使用 Renkit，防止覆盖中文版本。

## 本地检查

- `tests/test_themehub_pipeline.py`：仅本地 ZIP、静态语法树、受控渲染器和模拟发布；不执行上游插件。
- `tests/test_themehub_updates.sh`：临时目录内模拟安装、校验失败恢复、成功清理、缓存、禁止降级和设置保留。
- 旧版固定包与显示层测试继续保留，确保现有汉化没有退化。

Python 构建使用 3.12，Node 使用 22；客户端完整包检查兼容 SteamOS 的 Python 3，不需要翻译模型。仅云端处理有新增文字的版本时加载固定版本翻译依赖。
