# GFG Extreme 中文包

固定为用户指定 3.0 稳定系列的最新修订 3.0.10（源码 ea3826a4de3f0b11084ba1fa8b7fbbe84d7b8a14）。上游：https://github.com/wavessevaw/GFG-Extreme/releases/tag/v3.0.10 。上游已另有更高版本；本次不自动跨系列升级。

Renkit 入口：游戏与插件 → 其余常用插件 → 第二页。第一页保留封面、主题、传输与音乐；第二页为 GFG、Fantastic 与屏幕色彩。触控坐标和图形菜单均提供上一页、下一页及返回。

仅 Steam Deck LCD/OLED 与 SteamOS。插件以管理员权限运行；安装后在插件“设置”中安装引擎，保存工作并手动重启。首次运行按上游迁移规则清理旧 GFG/MAKO 运行组件并保留备份。避免与其他功耗工具同时启用。恢复时先在插件中移除引擎，再重启；仅删除插件目录不会撤销引擎。

上游标记此版为稳定，但发布说明明确尚未完成 Steam Deck 实机检查。本次只在 macOS 验证文件、渲染及模拟行为，未运行引擎、启动后台或执行功耗和系统改动，不将模拟结果当作硬件测试。

## 安装与完整性

保留原 ZIP 的全部运行文件、原作者与 GPL-3.0-or-later 许可证。提供带黄色“RenAmamiya汉化”的 Renkit 包；额外交付的完整中文 ZIP 不含此署名，可直接在插件商城的开发者设置中选择文件安装，无需再次解压内部文件。

复用现有下载清单与完整 SHA256 验证，设备端只解压经过白名单审核的中文成品，不在掌机上临时替换未知上游文案。按同一 GFG-Extreme 目录原子替换，准备失败保留原插件，自定义设置不删除；安装成功后复用插件重载流程。未加入新机初始化或一键组合，避免自动启用与已有功耗工具冲突的组件。

## 汉化边界与验证

四个页面、所有预设、19 种效果、动态帧率/功耗/运行状态、通知、诊断、记录与显示名称在渲染边界翻译。连接分支与 plugin.json 名称成对更新，API/RPC 名称、参数、数值与内部状态标识保持原样。显式原始日志、游戏名、文件路径、真实组件名与单位保留。完整文案清单见 data/gfg_extreme_ui_inventory.json；固定上游校验与文件清单阻止未经审核的更新。

HUD 仅替换显示文字，原始数字字形与控制逻辑保持不变。新增 Noto Sans SC 中文字形为 SIL OFL 1.1，保留字体许可证及对应生成代码；原 Inter 字形保持原样。包内提供与固定版本对应的前端源码及构建文件。

测试涵盖：真实编译产物 AST 比对、React + 模拟 Decky API v2/v1 后备连接、四页及分支、通知与异步状态、回调标识、完整 ZIP/文件权限、无署名包扫描、HUD 位图与字形、损坏/多余文件/链接拒绝、同目录替换和失败保留、重复安装及触控/GUI 翻页。未启动真实 Linux 后端。
