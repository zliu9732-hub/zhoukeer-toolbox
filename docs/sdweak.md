# SDWEAK 安装检查与修复

仅支持 Steam Deck LCD/OLED 和 SteamOS 3.9。原有机型核对、管理员确认、系统改动及安全保护风险提示保持不变；其他掌机禁止安装。

## 2026-10-22 排查结果

用户反馈下载进度走到 100% 后仍显示失败。逐个请求当前公开地址的七个分块，重组得到 6436400 字节的官方 SDWEAK 2.1 原包，SHA256 为 `5e91ca94577e3a999b6a8ea1a3e849bb168fedcc5b12b3cc41a00ca355d00d9e`。真实原包通过当前下载器的本地传输重放、全包校验和解压准备。因此没有把“文件源已损坏”当作已确认结论；没有设备日志，不能确定用户当次失败的具体网络退出码。

另在真实上游 `assets/SDWEAK.sh` 中复现了末尾状态错误：存在 TF 卡、最后一个可选设置不受支持时，即使 `FAIL=0`，脚本仍继承最后一次 `SKIP` 的退出码 1，令安装阶段的性能服务启动失败；反过来，最后一次写入成功也可能掩盖前面的实际写入失败。

## 当前安装方式

Renkit 原先已经省略了实验性显示组件替换，但每次仍下载两个没有使用的显卡组件。现在将其余 13 个上游原始文件组成约 20 KiB 的必需组件包，包含原作者、MIT 许可证、README 和原始脚本，随 Renkit 更新包一起提供。安装不再发起额外下载，不再依赖 GitHub、代理、分块请求或网络探测。

- 组件包：`assets/sdweak/SDWEAK-core-v2.2.0.zip`，19884 字节。
- SHA256：`b12b43bb4dfeb556d07111e77b17f2046ed0deb9ea8f6c4d6da9c90108dfa2f8`。
- 来源：官方 v2.2.0 原包。只移除 `assets/gamescope-3.16.30.1-2-SDWEAK.pkg.tar.zst` 和 `assets/vulkan-radeon-26.2.0.steamos_26.05-SDWEAK.pkg.tar.zst`；包内其余文件保持原字节。ZIP 条目按名称排序，时间统一为 2020-01-01、权限 0644、DEFLATE 级别 9，便于复现。
- `prepare_sdweak.py` 同时接受固定校验值的官方完整原包与必需组件包；逐项核对允许的文件、路径和链接后才准备安装副本。缺失或损坏时停止，明确提示尚未开始安装并更新 Renkit。
- 旧原包分块仍保留供旧版 Renkit 兼容使用，不修改原包的固定校验值。

准备副本时沿用之前的中文提示、管理员验证、只读状态恢复、禁止自动重启及软件签名保护。省略未使用的显卡组件检查，性能脚本按累计写入结果返回状态：可选项不存在时跳过，有实际写入失败或没有任何设置可应用时仍失败。服务使用当前用户目录，并按 systemd 规则转义空格、引号、反斜线和百分号，避免依赖固定用户名。

发生安装错误时，屏幕显示具体步骤，`~/SDWEAK-install.log` 记录步骤、行号、退出码及命令。启用性能设置、更新启动文件和更新开机设置分别记录，不再混成下载错误。失败可能已改变部分系统设置，不能宣称完整回滚；只读保护按原状态恢复。

## 验证范围

`tests/test_sdweak_prepare.py` 直接读取实际组件包，核对服务路径、可选项跳过、真实写入失败及修改后的安装器。性能脚本中的全部 `/proc`、`/sys` 路径映射到临时目录，权限、服务、启动文件操作由模拟命令代替。`tests/test_sdweak.sh` 验证无需网络即可完成准备、缺包/校验失败不会改变系统、失败和中断恢复只读状态；原下载兼容测试继续保留。macOS 不执行真实系统安装，实际 Steam Deck 运行需要实机确认。

## 3.2.7 系统保护状态查询

截图显示安装停在“无法读取系统保护状态，尚未开始安装”。旧代码把任何非零退出码视为查询失败；SteamOS 的 `status()` 在已关闭保护时明确输出 `disabled` 并返回 1，这是状态而非查询错误。之前模拟命令始终返回 0，漏掉了真实行为。现在通过现有管理员验证查询，接受 `enabled/0` 与 `disabled/0或1`，未知输出、真正失败以及 sysext 额外只读限制仍在安装前停止，保留原始诊断记录。

依据：公开的 Valve/Collabora `steamos-customizations` 脚本副本中 `steamos-readonly` 的 `status()` 实现：<https://gist.github.com/wallentx/98dc9fd124d34df52d5abb50975d3a90#file-steamos-readonly>。`tests/test_sdweak.sh` 模拟管理员权限要求、`disabled` 返回 1、异常/空/矛盾状态以及原只读状态恢复；未在 macOS 执行真实系统操作。

## 3.2.9 可选问题不可见

用户新截图显示已进入安装，最后输出“已应用显卡优化设置”。源码接下来进入启动设置及 LCD 提速/节能优先选择。原问题使用 Bash `read -rp`，提示写到 stderr 且没有换行；`launch.sh` 的 `filter_terminal_stderr` 按行读取，因此问题可以被暂存，而输入仍在等待。改成 stdout 的显式换行问题，然后单独 `IFS= read -r answer`，保留 y/N 和回车跳过，不自动同意改动。同时在已有失败步骤标签处打印当前步骤，避免更新启动文件时没有反馈。

`tests/test_sdweak_prepare.py` 增加真实 PTY 输入/输出、独立 stderr 的回归；对 Galileo 与 Jupiter 分别等待问题显示后才发送回车，确认跳过可选项并完成。权限与系统命令使用原测试的全量替身，macOS 不执行实际安装。
