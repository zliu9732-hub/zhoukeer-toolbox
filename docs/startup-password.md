# 启动时准备管理员密码

2026-10-24：触控入口与图形入口统一调用 `modules/password.sh startup`。通过既有验证函数尝试用户指定的默认密码 1234；成功后沿用安全写入函数保存本机桌面密码记录，不进入设置流程。验证不通过时，提示输入现有密码，验证成功后更新同一记录。不会自动调用 passwd 或修改系统密码。输入错误或取消时不覆盖原记录，保留原有重试、设置及退出入口。

软件安装的 `core/auth.sh`、`toolbox_sudo` 与密码读取规则保持不变：普通文件、当前用户所有、单硬链接、600 权限、密码只通过标准输入用于 sudo 验证，随后清除 sudo 缓存；密码不进入参数或日志。输入新的现有密码后，后续安装从这份记录自动验证，避免重复询问。默认密码验证失败并不单独证明密码不同（sudo 配置、账号权限等也可能影响验证），失败时不自动改变系统设置。

测试：`tests/test_startup_password.sh` 使用假 sudo 和临时记录，覆盖默认密码无输入跳过、已有旧记录更新、非默认密码录入、错误/无输入不覆盖，以及两种密码下实际 `toolbox_sudo` 自动验证。`tests/test_password_auth.sh` 回归现有密码设置、修改、记录权限与安装认证；`tests/test_touch_ui.sh` 核对触控入口。所有系统和认证操作均为模拟，macOS 不执行真实密码修改或安装。
