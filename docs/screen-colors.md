# 屏幕色彩（Screen Colors）

入口：游戏与插件 → 其余常用插件 → 屏幕色彩。提供影院、鲜艳、舒适、
类 OLED 效果，也可以分别调整色彩浓度、亮度、冷暖和红绿蓝强度。
只在游戏模式生效，随时可以恢复原始色彩。类 OLED 效果不能改变屏幕硬件。
此插件单独安装，不改变新机初始化或常用插件组合的内容。
