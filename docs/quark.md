# 夸克网盘

SteamOS 入口：常用软件 → 更多常用软件 → 夸克网盘（第一页，百度网盘下方）。图形菜单也有同名入口，用于上传、下载和管理夸克网盘文件。准备完成后从桌面或应用菜单打开并登录夸克账号。

从 Renkit 3.3.7 开始，按用户要求使用提供的 Windows 3.24.0 免安装版，直接放置主程序，不弹出安装器。沿用游戏启动器的存储位置选择、Proton 准备和国内下载代码。开发机是 macOS，仅核验文件与模拟流程；SteamOS 上的登录、上传、下载仍需实机验证。

## 来源与核验

- 用户提供：`夸克网盘_QuarkCloudDrive_v3.24.0_2026.3.23_C8B7C7AE.7z`，102438134 字节，SHA256：`f803768ab05478bc11cdc2a9cd7fa890121b2f2706bcc7ce337ff660736422ab`。这是用户指定的第三方整理免安装版，不宣称是官方原始发布包或经过厂商签名认证。
- 原包根目录 `quark-cloud-drive/QuarkCloudDrive.exe` 是启动入口，其 `app-3.24.0` 子目录包含主程序和资源。程序与附带许可证共 255 个文件，重打包时所有文件逐字节核对，未修改界面、程序或许可证，不添加汉化署名。
- 不分发根目录附带的 `去升级.bat`、`preference.json` 和整理者 README；批处理会删除并覆盖账号配置，预设包含其他人的账号标识和固定 Windows 盘符。Renkit 不执行这些脚本，也不向客户配置目录复制预设。`app-3.24.0` 内部原有文件全部保留。
- 分发文件 `QuarkCloudDrive-3.24.0-portable.tar.xz`，130338512 字节，SHA256：`55ac546da136b4f9680960390ef8604f96c2d73be29157f582ca831126ccca80`。复用 Gitee 清单与分块下载器，`quark-portable` 路由位于自有 `zhoukeer-toolbox-mirror-6`，按 8 MiB 拆为 16 块；清单内 `source_url` 仅标明软件官网，不作为此用户包的下载地址。
- 原 `quark` 的 7.4.2 安装器清单与历史文件不删除，供旧版 Renkit 兼容；新流程只接受固定免安装包 SHA256，不再回退到不同版本安装器。
- 图标仍是官网原图：`https://image.quark.cn/s/uae/g/3o/broccoli/resource/202602/f6439020-13b4-11f1-9342-3944993de2f6.png`。

## 安装与维护

先下载、核对完整包，再准备运行环境。`scripts/quark_portable.py` 检查全部文件路径、类型、大小与逐文件 SHA256；拒绝未知/重复路径、软硬链接及特殊文件。仅在同一存储位置的临时目录准备完整后放入 `drive_c/QuarkCloudDrive-Portable-3.24.0`，保留原程序、账号配置和下载内容。启动器工作目录指向程序所在目录。

已有完整免安装版会跳过下载与解压，仅修复 Renkit 管理的入口；已有相同目录但文件不完整或有异常链接时停止，不覆盖其中用户数据。请关闭程序后重命名该目录留作备份再重试。外接存储不可用、同名非 Renkit 入口及异常链接均停止，不转移数据。重复安装也保留新产生的账号文件。

安装不切换 SteamOS 只读状态，不使用管理员权限安装客户端，不重启 Steam。Proton 缺失时沿用现有 Steam 安装流程。`bash modules/quark.sh remove-shortcuts` 只移除 Renkit 创建的桌面和应用菜单入口，保留程序、账号及下载文件。

`tests/test_quark.sh` 使用临时文件、模拟下载和模拟 Proton；可传入实际分发包验证完整安装流程，绝不执行包内 EXE。`tests/test_quark_portable.py` 验证逐文件校验、异常包、链接、重复/越界路径、客户数据保留及失败清理。发布时从公开地址取回全部分块，重组核对完整 SHA256 与全部文件清单后才能发布 Renkit。二进制不进入主仓库或 v2 更新包。
