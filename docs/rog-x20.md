# ROG 20 周年 RC74XA 修复

入口：更多设置 → 掌机适配 → 更多掌机功能 → ROG 20 周年修复。图形菜单直接位于掌机适配。提供一键修复、查看状态和撤销。

只接受 ASUS RC74XA，音频 PCI 1022:15e2 / 1043:1954，Valve SteamOS 3.9.3，BIOS RC74XA.301 或 .303，内核 7.2.7-valve2-1-neptune-72-g31504582a073。必须读到扬声器 ID 0/1，不猜测、不混用固件，不降级、不强制加载、不为新内核临时编译。

范围：声音（含原包的麦克风/耳机配置）、右侧快捷菜单、唤醒后声音消失及控制器模式异常。振动、扳机振动、HDR、亮度、完整手柄识别、TDP 和风扇均不在本方案内。它是社区规避方案，不是 BIOS 更新或 ASUS 官方驱动，不保证所有问题都解决。安装后手动重启，在游戏模式逐项测试左右声道、麦克风、耳机、快捷菜单以及休眠唤醒。

安装需要管理员权限，会修改当前槽的 GRUB/ACPI 覆盖和声音配置，部署实验性模块和 X20 Fixes 插件，可能影响启动/声音稳定性。Renkit 会先校验和检查硬件，再沿用现有的管理员验证与商城安装逻辑；不修改密码，不清空其他插件，不强制重装已有商城。没有商城时先安装商城，因此此情况需要网络；修复文件随 Renkit 提供，不再次下载。商城若首次由 Renkit 安装，不属于本修复的撤销范围。

文件保存在 third_party/rc74xa-offline-20261024，逐文件 manifest 与入口固定清单 SHA256 校验。预编译模块、四份固件、前后端和许可与用户提供包一致；去除重复的 34MB 商城程序、独立商城源代码和证据缓存，保留实际修复源代码与上游归档。删除禁用的联网构建函数，增加目标目录类型检查。原独立安装说明中“本地安装商城”的部分不适用于本集成，详见 RENKIT-INTEGRATION.md。

备份在 /var/lib/rc74xa-offline，原音频数据在 /var/lib/ally-audio-fix；不要提前删除。安装失败会尝试恢复备份，恢复失败保留记录，不宣称完整自动回滚。系统/BIOS 更新前先撤销；卸载会核对安装后的 GRUB 哈希，变化时拒绝恢复旧配置，避免覆盖新系统启动文件。遇到这种情况保留备份与日志，再排查，不改目录名套用旧模块。
