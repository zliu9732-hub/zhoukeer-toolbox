# 屏幕色彩 中文版

原作者：PacificSilent；色彩引擎源自 Hooandee 的 panel-de-control。
许可证：GPL-3.0-or-later，原 LICENSE 与 CREDITS.md 完整保留。
汉化：RenAmamiya；上游版本：1.0.0；汉化修订：1。

可调整游戏模式下的屏幕色彩，提供影院、鲜艳、舒适和类 OLED 效果。
桌面模式下不生效；类 OLED 效果不能把 LCD 变成真正的 OLED 屏幕。

中文覆盖名称、页头、加载、无可用设备提示、所有效果、当前效果、
全部滑块、进阶开关及说明、恢复按钮和动态设备状态。
原 Python 后端、色彩算法、数值范围、预设、保存及自动恢复行为保持原样。
同一 Screen Colors 目录整体替换旧文件；不会删除用户设置。

随包附带 src/、pnpm-lock.yaml、rollup.config.js 和 tsconfig.json 对应源码。
完整上游源码：https://github.com/PacificSilent/decky-screen-colors/tree/3544b4925a8ac3c09bdbd124b92991ad369c9e37
汉化构建：https://github.com/zliu9732-hub/zhoukeer-toolbox （scripts/localize_screen_colors.py）。
